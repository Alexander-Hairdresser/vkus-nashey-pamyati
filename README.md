# Вкус нашей памяти

Сайт: https://alexander-hairdresser.github.io/vkus-nashey-pamyati/

Все девять записей и готовые формулы: https://alexander-hairdresser.github.io/vkus-nashey-pamyati/#hints

Приоритет звука: слово → сюжет → артефакт. Вкус не ограничивает прослушивание. В «Подсказках» у каждого файла четыре выбранных элемента, кнопки «Слушать» и «Собрать в колбе». Ручной выбор добавляет один слой за раз. Фразы сохраняются только в браузере посетителя.
